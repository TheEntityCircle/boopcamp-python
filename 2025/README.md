# Навигация
+ [first_day](https://github.com/TheEntityCircle/boopcamp-python/tree/master/2025/first_day) —
материалы первого дня буткемпа. Здесь разобраны основные конструкции языка Python, также есть примеры некоторых простых задач с решениями.

+ [second_day](https://github.com/TheEntityCircle/boopcamp-python/tree/master/2025/second_day) —
материалы второго дня. Разобраны базовые сценарии работы со строками, файлами, построение различных графиков с помощью matplotlib, умные numpy массивы и чтение из файлов различных типов.

+ [third_day](https://github.com/TheEntityCircle/boopcamp-python/tree/master/2025/third_day) — 
третий день. Здесь можно найти python скрипты, позволяющие подобрать коэффиценты функции по 
заданным значениям, а также базовые возможности языка вёрстки LaTeX.
